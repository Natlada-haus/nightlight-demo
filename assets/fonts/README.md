# ฟอนต์ที่ใช้ในเดโม

| ไฟล์ | ฟอนต์ | ใช้ที่ |
|---|---|---|
| `Anuphan-Variable.woff2` | Anuphan (variable, wght 100–700) — Cadson Demak | ทั้งแอป รวมหน้าอ่านนิทาน |

ฟอนต์นี้ใช้สัญญาอนุญาต **SIL Open Font License 1.1** (ข้อความเต็มใน `OFL.txt`)
แปลงจากไฟล์ .ttf ต้นฉบับเป็น .woff2 ด้วย fontTools โดยไม่ได้แก้ไขรูปอักษร และไม่ได้ใช้ชื่อสงวน (Reserved Font Name) ในทางที่ขัดกับสัญญา

หมายเหตุ (11 พ.ย. 2026, fix pass 2): เลิกใช้ Trirong แล้ว ลบไฟล์ Trirong-*.woff2 ออกจากโฟลเดอร์พรีวิว (ยังมีอยู่ใน ../nightlight-demo/)
