# ฟอนต์ที่ใช้ในเดโม

| ไฟล์ | ฟอนต์ | ใช้ที่ |
|---|---|---|
| `Anuphan-Variable.woff2` | Anuphan (variable, wght 100–700) — Cadson Demak | UI ทั้งหมด |
| `Trirong-Light.woff2`, `Trirong-Regular.woff2`, `Trirong-Medium.woff2` | Trirong — Cadson Demak | หน้าอ่านก่อนนอน |

ทั้งสองฟอนต์ใช้สัญญาอนุญาต **SIL Open Font License 1.1** (ข้อความเต็มใน `OFL.txt`)
แปลงจากไฟล์ .ttf ต้นฉบับเป็น .woff2 ด้วย fontTools โดยไม่ได้แก้ไขรูปอักษร และไม่ได้ใช้ชื่อสงวน (Reserved Font Name) ในทางที่ขัดกับสัญญา
